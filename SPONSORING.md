# Sponsoring Unichorn

Unichorn is an open-source PKI and digital-signature engineering project
maintained by **Harald Glab-Plhak**.

Sponsorship can help fund continued work on:

-   maintenance and dependency modernization,
-   PKI and signature interoperability,
-   automated tests,
-   certificate-validation test suites,
-   PKCS#11 hardware integration,
-   documentation,
-   security review,
-   build and CI improvements, and
-   research-oriented extensions.

## GitHub Sponsors

GitHub displays the **Sponsor** button for repositories through
`.github/FUNDING.yml`.

The included funding configuration contains a GitHub Sponsors entry for
`hglabplh-tech`. This only becomes active if that GitHub account or
organization is eligible for and has configured GitHub Sponsors.

If the actual Sponsors profile uses another GitHub username, change:

``` yaml
github: [hglabplh-tech]
```

to the correct Sponsors-enabled account.

## Other Funding Platforms

GitHub's funding configuration also supports selected external
platforms. Add only accounts that you actually operate.

Example:

``` yaml
# patreon: your-account
# ko_fi: your-account
# open_collective: your-collective
# custom:
#   - https://example.org/support
```

Do not uncomment placeholder entries until the corresponding funding
page exists.

## Sponsorship Principles

Sponsorship supports development but does not purchase control over the
project's security decisions, licensing, or technical conclusions.

Security-relevant changes should continue to be evaluated on technical
merit, interoperability, maintainability, and safety.

## Commercial or Institutional Support

Organizations interested in supporting a specific area---such as
interoperability testing, documentation, PKCS#11 device support, or
standards-oriented research---can open a GitHub issue to discuss the
scope publicly before work begins.

## Thank You

Financial support, code contributions, testing, documentation,
interoperability reports, and technical reviews are all valuable
contributions to Unichorn.
